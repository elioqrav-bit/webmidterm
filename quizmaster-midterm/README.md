## Project Description
QuizNova is a responsive quiz website where users can choose a category, answer timed questions, get an instant result and compare scores on a leaderboard.

## Pages
- Home
- Quiz
- Categories
- Leaderboard
- About
- Contact

## Features
- 30-question bank across 6 categories
- Random 10-question quiz mode
- 15-second timer for each question
- Instant answer feedback
- Local leaderboard with browser storage
- Responsive navigation and layouts
- Contact form with validation
- Bootstrap grid and utility classes

## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- LocalStorage
- GitHub Pages

## Run Locally
Open the project in IntelliJ IDEA and open `index.html` in a browser. For the best result, use IntelliJ's browser preview or any local static server.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Copy all files into the repository root.
3. Commit and push the project.
4. Open repository Settings → Pages.
5. Select the main branch and root folder.
6. Save and copy the generated website link.
